| 1（表紙） | 4 | 店舗外観／店内（席・照明）／ドリンクマシン／利用中の店内 |

## 要確認・要更新（重要）

1. **p25 の連絡先が未入力**。元資料のまま `XXX-XXXX-XXXX（担当：XXX）` / `aaaaa@aaaa.aaa` になっている。**必ず実際の値に差し替えること。**

2. **p8 の都道府県内訳が合計66店舗**（愛知35／大阪18／東京5／岩手2／岐阜2／埼玉1／千葉1／静岡1／滋賀1）。見出しは「70店舗以上」に更新済みだが内訳は元資料のまま。ラベルは「主な展開エリア」としてあるが、**70店舗の内訳に更新してほしい。**

3. **p9 の月次データは推定値**。元資料が画像だったため折れ線をピクセル追跡して復元している。ラベルのあった節目（2022.09=1／2023.09=2／2024.09=23／2025.09=48）には合わせ、末尾は70店舗に着地するよう調整した（末尾6ヶ月＝58/60/63/65/68/70）。**正データがあれば `build-deck.js` の `series` 配列を差し替えてほしい。**

4. **p10 の累計店舗数**（棒の相方の折れ線）も同じ推定値（1／1／9／22／32／46／51／68）。月間利用者数の8点は元資料にラベル表示されていた確定値。

5. **「104倍」**は元資料の記載をそのまま使用。ただし 101,343 ÷ 895 は約113倍で、104倍の基準月が資料から判別できなかった。ラベルは「立ち上げ当初比」と表記してある。

6. **元資料の記載が矛盾していた点**：日常業務の所要時間が p2/p3 では「1日15分程度」、p18 では「1日30分程度」。**全ページ「1日15分程度」に統一した**（15分が2箇所で記載されていたため）。30分が正しい場合は3箇所（p2・p3・p18＋表紙のチップ）を直す必要がある。

7. **p9 の「9都府県」** — 内訳は東北（岩手）〜関西（大阪・滋賀）まで。ラベルは「東北から関西まで広がる展開エリア」としている。

## 再生成

```bash
npm install                 # pptxgenjs, react-icons, react, react-dom, sharp
node build-icons.js         # → assets/icons/*.png（52種 × 5色）
node build-deck.js          # → selfcafe-fc-deck.pptx
```

フォントは元資料と同じ **Noto Sans JP**（数字はArial）を指定。Googleスライドなら標準で入っている。PowerPointで開く場合、Noto Sans JP が未インストールだと代替フォントに置き換わる。

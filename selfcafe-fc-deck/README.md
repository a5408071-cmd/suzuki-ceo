## 数値について（要確認）

グラフの元データは元資料に**画像として**入っていたため、数値を画像から復元している。

- **p10 の8点**（895 / 1,419 / 9,722 / 26,383 / 46,017 / 74,260 / 80,293 / 101,343）は元資料にラベル表示されていた確定値。
- **p9 の月次48点**は折れ線をピクセル追跡して復元した推定値。ラベルのあった節目（2022.09=1／2023.09=2／2024.09=23／2025.09=48／2026.08=65）には合わせてあるが、間の月は±1〜2店舗の誤差がありうる。**手元の正データがあれば `build-deck.js` の `series` 配列を差し替えてほしい。**
- **p10 の累計店舗数（棒の相方の折れ線）** も同じ推定値から各時点を拾っている（1／1／9／22／32／46／51／64）。
- **「104倍」**は元資料の記載をそのまま使った。ただし 101,343 ÷ 895 は約113倍で、104倍の基準月が何かは資料から判別できなかった。ラベルは「立ち上げ当初比」と表記してある。**基準を確認のうえ、必要なら数値を直してほしい。**

## 再生成

```bash
npm install          # pptxgenjs
node build-deck.js   # → selfcafe-fc-p2-10.pptx
```

フォントは既存資料と同じ **Noto Sans JP**（数字はArial）を指定している。Googleスライドなら標準で入っている。PowerPointで開く場合、Noto Sans JP が未インストールだと代替フォントに置き換わる。

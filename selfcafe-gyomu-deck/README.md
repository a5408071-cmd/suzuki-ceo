## FC資料から削除したページ

業務委託型では前提が異なるため、以下は載せていない。

- 自社物件の優位性（家賃ゼロ・回収期間） … 貴社は物件を用意して運営する立場ではない
- 初期費用：他社カフェ業態との比較 … 加盟金0円のため比較軸が成立しない
- 初期投資の詳細（積み上げバー） … 同上
- 収益シミュレーション 20坪／40坪（賃貸・自社） … 業務委託料25%の表に置き換え
- 投資回収シミュレーション／累計損益グラフ … 初期費用30〜50万円のため不要
- 出店事例：盛岡駅前店 … 加盟者が運営する前提の収益値のため

## 要確認事項

1. **収益シミュレーションの営業総利益（25坪888,100円／70坪1,387,600円）は元資料の値をそのまま使用しています。**
   FC資料側は1杯420円で再計算済みのため、こちらも420円ベースに更新するかご指示ください。
2. **通常のFC加盟の開業資金を「居抜き750万円〜／スケルトン1,050万円〜」に更新しました**（FC資料の最新値と一致）。
3. FAQ・貴社の業務ページは「運営主体は本部」の前提に合わせて文言を調整しています
   （営業届の申請・食品衛生責任者の設置はいずれも本部対応と記載）。

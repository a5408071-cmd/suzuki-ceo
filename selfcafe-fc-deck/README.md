### 未解決（要判断）

1. **p10「101,343人」「100,000杯突破」の定義が売上管理表と整合しない。**
   売上管理表の2026年7月「月間実杯数」は **83,654杯**（ドリンク単品ベース、客単価439円と整合）。
   サブスク売上6,555,298円ぶんの杯数は実杯数に含まれていないため、合算すれば10万杯を超える可能性はあるが、
   このシートからは確定できない。また「利用者数（人）」の管理はこのシートに存在しない。
   → 101,343人・100,000杯がどの指標・どのシステムの数値か確認のうえ、必要なら差し替えること。

2. **「104倍」の基準月が不明。** 101,343 ÷ 895（2023.01）は約113倍。ラベルは「立ち上げ当初比」と表記してある。

3. **p9の月次グラフは推定値。** 元資料が画像だったため折れ線をピクセル追跡して復元し、
   節目（2022.09=1／2023.09=2／2024.09=23／2025.09=48）と最終値71に合わせている。
   間の月は誤差がありうる。正確な開店月一覧があれば `build-deck.js` の `series` 配列を差し替えてほしい。
   なお「店舗一覧（店舗共有用）」に開店日の列は無く、「セルフ店舗リスト」は2025年11月開業までで更新が止まっている。

4. **p25の連絡先が未入力。** 元資料のまま `XXX-XXXX-XXXX（担当：XXX）` / `aaaaa@aaaa.aaa` になっている。
   **必ず実際の値に差し替えること。**

5. **元資料の記載が矛盾していた点：** 日常業務の所要時間が p2/p3 では「1日15分程度」、p18 では「1日30分程度」。
   **全ページ「1日15分程度」に統一した**（15分が2箇所で記載されていたため）。
   30分が正しい場合は4箇所（表紙のチップ・p2・p3・p18）を直す必要がある。

## 再生成

```bash
npm install                 # pptxgenjs, react-icons, react, react-dom, sharp
node build-icons.js         # → assets/icons/*.png（52種 × 5色）
node build-deck.js          # → selfcafe-fc-deck.pptx
```

フォントは元資料と同じ **Noto Sans JP**（数字はArial）を指定。Googleスライドなら標準で入っている。PowerPointで開く場合、Noto Sans JP が未インストールだと代替フォントに置き換わる。

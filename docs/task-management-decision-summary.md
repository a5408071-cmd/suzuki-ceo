# 社内タスク管理ツール検討まとめ（他セッション相談用）

作成日: 2026-08-13
検討者: 鈴木社長 + Claude Code

---

## 1. 目的・要件

- 欲しいのは**タスク管理のみ**（ガントチャート・工数管理などの本格的なプロジェクト管理は不要）
- 使い道:
  1. 社長と2社（ウッドデザインパーク / セルフカフェ）それぞれのマネージャーのタスク・進捗管理
  2. 社長＋マネージャーと各店舗のタスク・進捗管理
- 店舗数は約10。想定利用者は社長＋マネージャー数名＋各店長で**合計15人前後**
- 店舗スタッフは非IT。スマホでの使いやすさが重要

## 2. 検討の経緯

### 自作 vs サービス契約
- 当初は自社開発も検討 → **サービス契約を推奨**と結論
- 理由: 開発・保守コストが契約費用を大きく上回る。スマホアプリ・通知の品質を自作で出すのは困難。「簡易」で作ると現場に定着しないリスク大
- 自社開発の再検討は、運用後に「他システム連携が必要」「人数増で年額数十万円規模」「具体的な不満の蓄積」が出てきた段階で

### Jooto（当初の第1候補）は消滅
- 当初はJooto（国産・シンプル）を第1候補にしたが、**運営元PR TIMESが2026年8月6日にJooto事業廃止を正式決議**
- 2027年7月31日で一般提供終了、**新規契約はすでに受付停止** → 選択肢から除外
- 出典: https://prtimes.jp/main/html/rd/p/000001691.000000112.html

### 最終候補の比較
| | Trello Standard | Backlog スターター |
|---|---|---|
| 料金 | 1人月約$5（約780円）/ 15名で月1.2万円 | 月2,970円固定（30名まで） |
| 強み | 圧倒的な使いやすさ・スマホアプリ | 安さ・国産・日本語サポート |
| 弱み | 人数課金 | プロジェクト5個まで・画面がやや複雑 |

## 3. 結論（現時点）

**Trelloを採用。まず無料プランで開始。**

タスク管理のみが目的なら、Trello無料プラン（1ワークスペース: メンバー10人・ボード10枚まで）を**会社ごとにワークスペースを分けて**使えば0円で収まる見込み:

| ワークスペース | メンバー | ボード |
|---|---|---|
| ウッドデザインパーク | 社長＋WDPマネージャー＋WDP各店長 | 経営ボード1枚＋店舗別ボード |
| セルフカフェ | 社長＋SCマネージャー＋SC各店長 | 経営ボード1枚＋店舗別ボード |

- 各ボードのリストは「やること → 進行中 → 完了」の3本のシンプル構成
- 社長は両ワークスペースに参加して全体を横断確認
- 片方が10人を超えたら、そのワークスペースだけStandard（1人月約780円）へ

## 4. 次のアクション

1. Trello無料アカウント作成（ https://trello.com/ja/ ）
2. 2社分のワークスペースと経営ボードを作成
3. 社長＋マネージャーで1週間試験運用
4. 問題なければ各店長を招待して店舗ボードを展開

## 5. 未決事項（他セッションで相談したいこと）

- ワークスペース／ボードの詳細設計（店舗ボードのリスト構成、ラベル運用ルール）
- 店長への展開手順・使い方の説明方法
- 10人制限を超えた場合のStandardプラン移行判断
- 運用ルール（タスクの起票基準、期限設定、完了の定義、週次での見返し方法）

### 契約期間の考え方（p3）

内装工事費を当社が負担するため、回収に一定の期間が必要という理由づけで3年以上を基本とし、
今回は特約として2年からでも同条件とする、という構成にしている。

| 区分 | 期間 | 位置づけ |
|---|---|---|
| トライアル期間 | 1年 | 販売杯数と運営負荷をご確認いただく期間 |
| 基本契約 | 3年〜 | 当社の投資回収に必要な期間 |
| 今回の特約 | 最低2年〜 | 3年以上と同じ条件でお受けする |

**「特別条件」という呼称は資料から外した**（2026年9月20日のご指示）。
月額固定5万円は本編と同じく支払条件の一部として記載し、今回の譲歩は契約期間の特約に置いている。

### 費用と所有の区分（p3の表）

| 項目 | ご手配・ご負担 | トライアル終了後 |
|---|---|---|
| 内装工事（造作・床・サイン） | セルフカフェ | そのまま残る |
| 家具・什器（テーブル・椅子・植栽 等） | 未来屋書店様 | 御社の資産として残る |
| ドリンクマシン・決済端末 | セルフカフェ | 当社が撤去 |
| 防犯カメラ・通信機器 | セルフカフェ | 当社が撤去 |
| 原料・機器メンテナンス | セルフカフェ | — |
| 水道光熱費・通信費・消耗品 | 未来屋書店様（実費） | — |
| 原状回復 | 不要（義務なし） | — |

水道光熱費・通信費・消耗品の負担区分は本編（`../selfcafe-miraiya-deck`）と揃えている。

## 要確認事項

1. **トライアル期間（1年）と基本契約期間の通算の扱いが未整理。**
   「トライアル1年のあと別途3年」なのか「トライアル1年を含めて通算3年」なのかで
   相手の受け取り方が変わる。資料では注記で「契約書にて明記させていただきます」と
   逃げているが、決まっていれば本文に書いたほうが強い。
2. **対象店舗が未確定。** 表紙は秋田店・土浦店の両方を記載し、本文では
   「対象店舗はご相談のうえ決定」としている。1店舗からの開始であればその旨を明記する。
3. **「スタンダード仕様」の呼称**は本編と同じくこちらで付けた説明用の呼び方。
4. **什器の概算費用は未記載。** レイアウト確定後の見積り扱いとしている。
   概算レンジを出せるのであれば、御社のご負担額が見えるので記載したほうが判断しやすい。

### 通常契約との比較（p3）

**先方から「3年はリスクが大きいので1年で」と打診があったため、1年のトライアルとして提案する構成に
変更した（2026年9月21日）。2年目以降の条件には触れていない。**

| 項目 | 通常のご契約 | 今回のトライアル |
|---|---|---|
| 契約期間 | 3年〜 | **1年** |
| 内装仕様 | プレミアム仕様 | プレミアム仕様（同じ） |
| 内装工事費 | セルフカフェが負担 | セルフカフェが負担（同じ） |
| 家具・什器 | 御社にてご手配（御社の所有） | 御社にてご手配（同じ） |
| 御社のご負担 | 家具・什器のご手配のみ | 家具・什器のご手配のみ（同じ） |
| お支払い | 売上の25％ ＋ 月額固定5万円 | **売上の25％** |
| 原状回復義務 | なし | なし（同じ） |

**違いは契約期間と月額5万円の2点だけ**、という打ち出し。
「期間を1年に短縮する分、月額固定5万円はお付けしていない」と明記し、
それ以外は通常契約と同条件であることを示している。

### 費用と所有の区分（p3の表）

| 項目 | ご手配・ご負担 | トライアル終了後 |
|---|---|---|
| 内装工事（造作・床・サイン） | セルフカフェ | そのまま残る |
| 家具・什器（テーブル・椅子・植栽 等） | 未来屋書店様 | 御社の資産として残る |

| 原状回復 | 不要（義務なし） | — |

水道光熱費・通信費・消耗品の負担区分は本編（`../selfcafe-miraiya-deck`）と揃えている。

## 要確認事項

1. **対象店舗が未確定。** 表紙は秋田店・土浦店の両方を記載し、本文では
   「対象店舗はご相談のうえ決定」としている。1店舗からの開始であればその旨を明記する。
2. **「スタンダード仕様」の呼称**は本編と同じくこちらで付けた説明用の呼び方。
3. **什器の概算費用は未記載。** レイアウト確定後の見積り扱いとしている。
   概算レンジを出せるのであれば、御社のご負担額が見えるので記載したほうが判断しやすい。

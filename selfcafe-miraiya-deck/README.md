参考店（印西牧の原40.6杯・新守山45.2杯）は社内管理台帳の実績値のため変更していない。

## 費用負担の区分（2026年9月1日修正）

**水道光熱費は本部負担ではなく貴社ご負担。** 以下のとおり修正した。

| 項目 | 業務委託型（本提案） | FCプラン |
|---|---|---|
| 原料・機器・メンテナンス | 本部負担 | 貴社負担 |
| **水道光熱費・通信費** | **貴社ご負担（実費）** | 貴社負担 |

   ささしまライブ店（外観・内観）と印西牧の原店（3カット）を使用しています。

   赤字額にも触れていません。
3. **既存什器の再利用可否・工事範囲は現地確認前のため未記載です。**
   初期費用は業務委託型の標準（30〜50万円・機器設置費のみ）で置いています。
4. **月間来客数（秋田3,760人／土浦4,027人）は貴社ご提供資料の2025年平均をそのまま使用しています。**
5. **60坪・40坪・30坪という区分は汎用の坪数レンジです。** 秋田店は62.97坪・土浦店は30坪のため、
   60坪＝秋田・30坪＝土浦とほぼ対応するが、他店舗への横展開を想定した一般形として掲載している。

6. **FCプランの試算は「ご参考」として掲載しています。** 今回のご提案は業務委託型であり、
   FCプランは貴社が運営主体・初期投資900万円程度・売上変動リスクも貴社という前提。
   相手先に投資を促す意図がないなら、p13・p14は社内説明用として外すこともできます。

## 要確認事項

1. **月額固定5万円の扱いが未確定。**
   本編の特別条件は「売上の25％ ＋ 月額固定5万円」だが、いただいた条件には歩合25％のみ
   記載されていたため、この資料では**25％のみ**で記載している。
   トライアル中も5万円が付くのであれば追記する。
2. **トライアル期間が未確定。** 資料では「期間はご相談のうえ決定」としている。
   「3ヶ月」「6ヶ月」など具体的な期間が決まっていれば明記したほうが伝わる。
3. **対象店舗が未確定。** 表紙は秋田店・土浦店の両方を記載し、本文では
   「対象店舗はご相談のうえ決定」としている。1店舗からの開始であればその旨を明記する。
4. **「スタンダード仕様」の呼称**は本編と同じくこちらで付けた説明用の呼び方。
5. **什器の概算費用は未記載。** レイアウト確定後の見積り扱いとしている。
   概算レンジを出せるのであれば、御社のご負担額が見えるので記載したほうが判断しやすい。

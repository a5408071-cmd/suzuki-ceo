### 通常契約との比較（p3）

**先方から「3年はリスクが大きいので1年で」と打診があったため、1年のトライアルとして提案する構成に
変更した（2026年9月21日）。2年目以降の条件には触れていない。**

| 項目 | 通常のご契約 | 今回のトライアル |
|---|---|---|
| 契約期間 | 3年〜 | **1年** |
| 内装仕様 | スタンダード仕様 | スタンダード仕様（同じ） |
| 内装工事費 | セルフカフェが負担 | セルフカフェが負担（同じ） |
| 家具・什器 | **セルフカフェが準備** | **御社にてご手配（御社の所有）** |
| お支払い | 売上の25％ ＋ 月額固定5万円 | **売上の25％** |
| 原状回復義務 | なし | なし（同じ） |

**違いは3点**（契約期間・家具什器の手配・月額5万円）という打ち出し。
金色でハイライトしている行がちょうど3行になるよう、重複する「御社のご負担」の行は削除した。
「1年でご判断いただける代わりに、家具・什器のご手配と月額5万円の2点をご調整ください」と
対価関係を明示している。

**家具・什器は本来セルフカフェが準備する**（2026年9月21日のご指摘）。
トライアルで御社ご手配としているのは、終了後もそのまま残す前提で御社の資産にしておくため。
ただしこの理由は資料上では説明しない（上記のとおり説明ページは削除済み）。

## 要確認事項

1. **対象店舗が未確定。** 表紙は秋田店・土浦店の両方を記載し、本文では
   「対象店舗はご相談のうえ決定」としている。1店舗からの開始であればその旨を明記する。
2. **「スタンダード仕様」の呼称**は本編と同じくこちらで付けた説明用の呼び方。
3. **什器の概算費用は未記載。** レイアウト確定後の見積り扱いとしている。
   概算レンジを出せるのであれば、御社のご負担額が見えるので記載したほうが判断しやすい。

収益シミュレーションは指示により再計算済み（2026年8月25日）：
**20坪40席＝1杯420円×75杯／日（利益27.0万円／月）、50坪90席＝1杯420円×110杯／日（利益40.28万円／月）**。
50坪の杯数110杯／日は 20坪75杯からの席数比の補間値のため、実態に合わせて要確認。出店事例（盛岡駅前店）はFC資料の実績値のまま。

## 要確認事項

1. **業務委託型資料側の「通常のFC加盟」列と50万円のずれが残っています。**
   業務委託型資料は「加盟金100万円＋工事費用等（開業資金目安：居抜き700万円〜／スケルトン工事1,000万円〜）」と記載。
   本資料は内訳の足し算に合わせて**居抜き650万円〜／スケルトン950万円〜**としました（加盟金100＋工事400＋準備金100＋保証金50＝650）。
   業務委託型側は「目安」表記なので丸めの範囲ともいえますが、両資料を揃えるなら業務委託型側を650／950に直すのが整合的です。

2. **日常業務の所要時間を「1日15分」に統一しました。** 元FC資料は「1日30分程度」でした。
   30分が正しい場合は、表紙・p5・p17の3箇所を修正してください。

3. **p9の指標を「月間販売杯数」から「月間利用者数」に変更しました。** 数値を業務委託型に合わせる指示のため、
   同資料の系列（人ベース）を採用しています。杯数で見せたい場合はご指示ください。

4. **p28の連絡先が未入力です。** 元資料のまま `XXX-XXXX-XXXX（担当：XXX）` / `aaaaa@aaaa.aaa` です。
   **必ず実際の値に差し替えてください。**

5. **SEO対策・MEO対策を「標準提供（費用なし）」として明記しました。** 元FC資料で初期費用・月額とも0円だったため、
   有料オプション表の中で無料項目であることが分かるようにしています。

6. **店舗数を71店舗・11都府県（2026年7月時点）に更新しました。** 業務委託型資料および
   社内データ（「店舗一覧（店舗共有用）」2026/07/21更新）と同じ値です。

7. **p6「活用可能性」は佐藤様のご提案をもとに新規作成したページです。**
   「集客できる」で止めず、まちづくり／セミナー・イベント／物販という三方向の使い方と、
   地方都市ほど競合がいない点（盛岡駅前店の実績を根拠）を提示しています。
   **貸しスペース・物販の可否は立地と契約条件で変わるため、ページ下部に注記を入れています。**
   本部として実際にどこまで許容するか（物販の仕入れ主体、イベント利用時の課金など）は運用ルールの確定が必要です。

8. **p26 FAQに「許認可の申請は必要ですか？」を追加しました。**
   回答は「営業届の提出と食品衛生責任者の設置が必要／資格は貴社にて取得／営業届の申請は本部が行う」としています。
   保健所の運用は自治体差があるため、文言はこのままで問題ないかご確認ください。

9. **p22「投資回収シミュレーション（75坪・初期費用1,000万円）」は1杯420円ベースです。**
   売上163.8万円／月（420円×130杯×30日）・経費64.86万円／月（家賃除く）。
   家賃あり（坪8,000円）は月次利益38.94万円で回収約26ヶ月（約2年2ヶ月）、家賃なし（自社物件）は98.94万円で回収約10ヶ月。
   杯数（130杯／日）・坪単価の前提はご確認ください。

10. **p16の写真は業務委託型資料の同ページで使われていた店内写真です。**
   モニタリング画面のスクリーンショットに差し替える場合は `assets/photos/p16-support.jpg` を置き換えてください。

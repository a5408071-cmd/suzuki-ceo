- 工期約1か月は**残置が前提**。スケルトン戻しになると2月末オープンが厳しくなる
- **ネット回線は申込から開通まで1〜2か月**。12月中に申し込まないと2月末に間に合わない
- **1/31閉店 → 2/28オープンは正味28日でバッファゼロ**。閉店を1月中旬〜下旬に前倒しできると安全
- 館（イオンモール）の工事申請期間は未織り込み
- フッターに**「業務委託型のため工事費のお見積り提出はございません。ご負担は設置工事費のみ」**を明記
- **契約締結に必要な項目**（開業日の確定／ご契約者情報／お振込先口座）を未来屋書店様側に追加（10/17）

## 工期の根拠

**本編（`../selfcafe-miraiya-deck`）の「現地確認から最短2〜3ヶ月」を内訳に分解したもの。**

### ① 閉店後に必要な期間（合計3〜4週間）

| 工程 | 期間 | 備考 |
|---|---|---|
| 残置物の撤去・下地調整 | 3〜5日 | クリエ様の原状回復範囲により変動 |
| 内装工事（造作・床・サイン） | 2〜3週間 | スタンダード仕様の場合 |
| 機器設置・試運転・什器搬入 | 3〜5日 | 電源・給排水が既存で使える前提 |

### ② 閉店前から動かす期間

什器・機器の発注リードタイム **4〜6週間**。工事は閉店後だが、発注だけは閉店前に必要。
発注にはレイアウトと坪数（30坪／60坪）の確定が前提。

### 逆算した期限

| 期限 | 内容 |
|---|---|
| 10月中 | 現地確認 |
| 11月中旬 | 坪数・レイアウトの確定 |
| **12月上旬** | **什器・機器の発注（工程上の分岐点）** |
| 1月末 | クリエ閉店・退去 |
| 2月末 | オープン |

**この数字は社内の実績値ではなく、本編の「最短2〜3ヶ月」から逆算した当社仮定です。**
実際の施工実績・什器の納期が分かれば差し替えてください。特に次の3点は要確認：
1. 内装工事2〜3週間（スタンダード仕様・30坪／60坪で差があるか）
2. 什器・機器のリードタイム4〜6週間（実際の仕入れ先の納期）
3. 館（イオンモール）の工事申請に要する期間は**未織り込み**（申請期限が判明次第、工程に追加）
